# Декор — оформление мероприятий

Учебный веб-проект для презентации услуг студии оформления праздников и сбора первичных пожеланий клиентов.

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Перейдите к услугам и заполните демонстрационную форму заявки.

## Файлы
- `index.html` — адаптивный интерактивный прототип сайта.
- `business_requirements.md` — проблема проекта, бизнес-требования, правила и критерии приёмки.
- `diagrams.md` — три UML-подобные диаграммы на русском языке в формате Mermaid.

## Функциональность прототипа
- презентация услуг студии;
- отображение ориентировочных цен;
- навигация по разделам сайта;
- форма заявки с обязательными полями;
- проверка формы и сообщение о заполнении.

## Ограничения
Заявка не отправляется на сервер и не сохраняется в базе данных. Цены и содержимое демонстрационные. Для реального бизнеса нужно добавить серверную обработку, защищённое хранение заявок и реальные контакты.
